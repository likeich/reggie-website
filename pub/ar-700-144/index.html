AR 700-144 — Demilitarization And Trade Security Controls

AR 700-144 governs Army participation in the DoD Demilitarization and Trade Security Controls Program, including DEMIL coding.

  • Publication number: AR 700-144
  • Title: DEMILITARIZATION AND TRADE SECURITY CONTROLS
  • Date: 12/15/2022
  • Proponent: G-4
  • Status: ACTIVE

View AR 700-144 on armypubs.army.mil

AR 700-144 addresses demilitarization policy, qualified recycling, disposal plans, personnel training, code challenges, and donations of Army-managed equipment. It requires procedures for demilitarization coding, trade security controls, plan preparation, and the safe, environmentally acceptable disposal of items.

Questions and answers

Can excess property be sold through any recycle program?

Excess property, with the exception of firing range-expended brass and mixed metals gleaned from firing range cleanup, MLI, and/or CCLI (including demilitarized MLI) as defined in the DoDM 4160.28, Volumes 1, 2, and 3, will not be sold through any recycle program. (paragraph 3-2)

How must firing range-expended brass and mixed metals be sold?

Firing range-expended brass and mixed metals gleaned from firing range cleanup will only be sold through a qualified recycle program (see DoDI 4715.23) for the definition of qualified recycle program excluded materials). (paragraph 3-2)

Who must complete the Defense Demilitarization Program Course?

The DDPC is mandatory for all Army personnel responsible for the management, administration, and/or oversight of any aspect of the DEMIL and/or TSC programs. (paragraph 1-1)

How quickly must Army DEMIL code challenges be answered?

The DC, item managers, and equipment specialists must answer DEMIL code challenges within 60 days, with appropriate changes recorded in the FLIS. (paragraph 1-1)

When is a DEMIL and disposal plan required?

A DEMIL and disposal plan is required prior to the operational test and evaluation milestone of any system and/or item development, as well as any major modification or upgrade to an existing system. (paragraph 1)
