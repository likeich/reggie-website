AR 70-76 — Joint Electronics Type Designation Automated System {secnavinst 2830.1a; Afi 60-105}

AR 70-76 governs the Joint Electronics Type Designation Automated System for identifying and naming electronic materiel.

  • Publication number: AR 70-76
  • Title: JOINT ELECTRONICS TYPE DESIGNATION AUTOMATED SYSTEM {SECNAVINST 2830.1A; AFI 60-105}
  • Date: 09/03/2024
  • Proponent: ASA (AL&T)
  • Status: ACTIVE

View AR 70-76 on armypubs.army.mil

It establishes requirements for JETDAS administration, access, DD Form 61 submissions, type designators, and nomenclature. It also identifies covered electronic materiel and sets rules for classified requests and assigned designators.

Applies to: In accordance with MIL STD 196G, the JETDAS was established to standardize the preparation of DD Form 61 and the assignment of type designators for electronic materiel.

Questions and answers

What is JETDAS used for?

JETDAS will be used for all nomenclature (approved item name and type designator) requests of unclassified materiel. (paragraph 1-1)

How must classified materiel nomenclature requests be submitted?

Classified materiel nomenclature requests must be submitted via DD Form 61 (Request for Nomenclature) in hard copy format due to classified information. (paragraph 1-1)

What happens when a type designator is assigned?

Once assigned, the type designator cannot be duplicated or changed and will always apply to one specific item. (paragraph 3-1)

What information is loaded into JETDAS for classified requests?

For classified request, only the approved item name and type designator information (unclassified information) will be loaded in JETDAS, all other information for classified requests will be submitted in hard copy format on the DD Form 61 that meets appropriate classification requirements. (paragraph 2-1)

What must the originator do to obtain a type designator and nomenclature?

The originator will construct a proposed type designator in accordance with MIL STD 196G and submit a completed DD Form 61, through JETDAS, to the agency DCP. (paragraph 3-1)
